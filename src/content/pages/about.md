Hi, I'm **Jimmy Huang** — a backend engineer from Taiwan focused on infrastructure and security. Certified Ethical Hacker (CEH).

This blog is where I write about backend engineering, DevOps, infrastructure, and security — lessons from work, my home lab, and side projects.

## How this blog works

- Posts are written in **Obsidian** and live in a private vault.
- A GitHub Action syncs them into this repo, which is built with **Astro** ([AstroPaper](https://github.com/satnaing/astro-paper) theme).
- Another Action builds the static site and deploys it to a self-hosted VPS via rsync.
